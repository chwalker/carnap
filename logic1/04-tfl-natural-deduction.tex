the size of a truth table is $2^n$ lines. A familar number to computer
scientists, but let's pause to consider how fast this number gets very very big.

It is not easy to glean insights from such a table and questions about
\emph{why} an argument is correct become extremely obscure. We'd really like
to get both the result \textbf{and} a story about its justification from the
same process. 1000+ line truth tables are just a bad machanism to provide that.
As much work as the simplified and partial truth tables help us save, we are
still left with the impression that the process should be more constrained and
rule-based.

We face similar problems with simplifications like \emph{proof trees}, which
still have a $2^n$ search space, despite less writing and better odds of not
needing to explore it all (for the simple cases).

Ideally, we'd like to be able to evaluate the semantic properties of an argument
in TFL on the basis of formal practices alone. This is the basic idea behind
\emph{natural deduction}. We will use \emph{proofs} that allow us to demonstrate
the truth of some TFL sentences when we assume the truth of other TFL sentences.
In a sense these proofs leverage rules reflecting the intuitions that we put to
use last week in quickly working through our partial truth tables to find
counter-examples.

\subsection{Preliminaries}

In the last lecture or two, we have sometimes used greek letters \ephi, \spsi
and \schi in truth tables and definitions as a stand-in for \textbf{any} TFL
sentence, not just atomic sentences. But more broadly, we can think of formulas
like these as \emph{schemas}. They each represent an entire class of sentences.

We already discussed schemas informally in Obs.
\ref{obs:argument-proto-schemas}, but we can firm up some concepts now before we
start to use them in defining the rule system of \emph{natural deduction}. In
an argument schema, a given \emph{metalogical variable} always stands for the
same thing, that's the whole point of using them. Will need to add a few new
definitions.

\begin{definition}[Substitution Instance]
  A \emph{substitution instance} of a metalogical schema \schi is any wff \sphi
  that can be made by substituting a wff $\epsi_i$ for each of the metalogical
  variables $\egamma_i$ in \echi.
\end{definition}

Substitution instances make it possible for us to generalize the notion of
\emph{form} into \emph{metalogical schemas}.

\begin{definition}[Form of a Well-Formed Expression]
  A wff \sphi of a logic has the \emph{form} of a metalogical schema \schi iff
  \sphi is a substitution instance of \echi. 
\end{definition}

Turning things around, we can make schemas by generating substitution instances
of the well-formed formulas of a language.

\begin{definition}[Basic Schema]
  A \emph{basic schema} \schi is a metalogical expression that is obtained from
  a well-formed formula \sphi of the relevant logic by replacing each of the
  content symbols in \sphi with a consistent metalogical variable (i.e. each
  symbol A in \sphi always gets replaced by the same metalogical variable
  $\psi_i$ and no other symbol B is also replaced by $\psi_i$ but by some other
  variable $\psi_j$).
\end{definition}

The ones we make from tautologies are \emph{tautological schemas}. When we note
that some wff is a substitution instance of a tautological schema, we can say
that it is \emph{valid in virtue of its form}. Similarly, when we schematize an
argument, we can say that it is a \emph{tautological argument schema} just in
case its simplest substitution instance\footnote{This is just the argument that
results the from consistent replacement of each metalogical variable with an
atomic sentence letter.} is a tautologically valid argument.

\subsection{Defining Proofs and Rules}

We begin with a basic definition of proofs (aka \emph{derivations}).

\begin{definition}[Proof]
  \label{def:formal-proof}
  A \emph{proof} in Truth Functional Logic is a sequence of sentences that:
  \begin{enumerate}
  \item Begin with zero or more \emph{premises}
  \item Introduce new sentences only when they can be made by applying
    \emph{rules} to lines already in the proof
  \item End with a \emph{conclusion} (the sentence that we want to prove)
  \end{enumerate}  
\end{definition}

We have two kinds of rules in a Fitch-style natural deduction system:
\begin{enumerate}
\item \textbf{Introduction Rules:} that allow us to work toward a conclusion
  containing the operator being introduced; and
\item \textbf{Elimination Rules:} that allow us to break down sentences that
  are already in the proof so that we can get at the parts.
\end{enumerate}  

Before we get into the rules themselves, we should pause for a minute and
discuss the styles and formats of the proofs themselves. First, we will
separate the premises from the rest of the proof with a horizontal line. Second,
we will number each line to make it easier to reference later in the proof. 
Finally, we will mark every line with a \emph{justification}. This will be the
rule applied along with the previous lines that it was applied to. We will mark
premises with their own justification $PR$, which just indicates that we take
them to be true by assumption.

\vspace{-0.5\baselineskip}
\begin{fitchproof}
\hypo {1} {P\eand Q} \by{PR}{}
\have {3} {P}        \ae{1}
\end{fitchproof}

In this simple proof, we show that we can conclude $P$ if we assume $P\eand Q$.
In other words, $P\eand Q\eproves P$. The single premise ($P\eand Q$) is marked
``PR'' and the conclusion is the sentence on the final line ($P$).

\subsection{Rules of Natural Deduction}

The simplest rule in the system is simply that we can repeat lines that we have
already seen.

\Needspace{5\baselineskip}
\begin{fitchrule}[Repitition]
  \label{def:repitition-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \have[m]      {1} \ephi
    \have[\vdots] {2} {\vdots}    
    \have[n]      {3} \ephi    \r{1}
  \end{fitchproof}
  \vspace{-0.9\baselineskip}
  where $m<n$
\end{fitchrule}

Trivially, we could use this to prove $\ephi\eproves\ephi$.

\begin{fitchproof}
  \have[] {1} \ephi \by{PR}{}
  \have[] {2} \ephi \r{1}
\end{fitchproof}

For each of the operators, we will want to introduce a pair of rules: one an
\emph{introduction rule} and the other an \emph{elimination rule}.

\subsubsection{Rules for Conjunction}

Conjunction has the most straightforward rules. When both conjuncts occur in a
proof, we can introduce a conjunction of them.

\Needspace{6\baselineskip}
\begin{fitchrule}[\eand-Introduction]
  \label{def:and-introduction-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \have[m] {1} {\ephi}
    \have[n] {2} {\epsi}
    \have[ ] {3} {\ephi\eand\epsi} \ai{1,2}
  \end{fitchproof}
\end{fitchrule}

When a conjunction occurs in a proof, we can eliminate it for either of the
conjuncts.

\Needspace{5\baselineskip}
\begin{fitchrule}[\eand-Elimination]
  \label{def:and-introduction-rule}
  \leavevmode
  There are two rules for \eand-elimination, one for each conjunct: \\
  \twoitems{
  \begin{fitchproof}
    \have[n] {1} {\ephi\eand\epsi}
    \have[ ] {2} {\ephi}              \ae{1}
  \end{fitchproof}
  }{
  \begin{fitchproof}
    \have[n] {1} {\ephi\eand\epsi}
    \have[ ] {2} {\epsi}              \ae{1}
  \end{fitchproof}
  }
\end{fitchrule}

With just the introduction and elimination rules for \sand we can prove many
valid arguments such as $A \eand B, C \eand D \therefore A \eand D$.

\begin{fitchproof}
  \hypo {1} {A \eand B} \by{PR}{}
  \hypo {2} {C \eand D} \by{PR}{}
  \have {3} {A}         \ae{1}
  \have {4} {D}         \ae{2}
  \have {5} {A \eand D} \ai{3,4}
\end{fitchproof}

\subsubsection{Rules for Conditionals}

The elimination rule (modus ponens) is straightforward so we will start there.

\Needspace{6\baselineskip}
\begin{fitchrule}[\eif Elimination]
  \label{def:if-elimination-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \have[m] {1} {\ephi\eif\epsi}
    \have[n] {2} {\ephi}
    \have[ ] {3} {\epsi}           \ie{1,2}
  \end{fitchproof}
\end{fitchrule}

Adding modus ponens gives us more tools to explore multi-step arguments in
proofs:

\begin{fitchproof}
  \hypo {1} {A \eand B} \by{PR}{}
  \hypo {2} {B \eif  C} \by{PR}{}
  \have {3} {B}         \ae{1}
  \have {4} {C}         \ie{2,3}
\end{fitchproof}

So far, pretty simple. But for the introduction rule, we will need to make use
of assumptions that are not included in the premises. We will mark their
introduction with a new horizontal line and a justification of AS.

\Needspace{6\baselineskip}
\begin{fitchrule}[\eif Introduction]
  \label{def:if-introduction-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \open
    \hypo[i] {1} {\ephi}           \by{AS}{}
    \have[j] {2} {\epsi}
    \close
    \have[ ] {3} {\ephi\eif\epsi}  \ii{1-2}
  \end{fitchproof}
\end{fitchrule}

Here is a simple proof using both the introduction and elimination rules for
conditionals.

\begin{fitchproof}
  \hypo {1} {A \eif (B \eif C)} \by{PR}{}
  \open
  \hypo {3} {B}        \by{AS}{}
  \open
  \hypo {3} {A}        \by{AS}{}
  \have {4} {B \eif C} \ie{1,3}
  \have {5} {C}        \ie{2,4}  
  \close
  \have {6} {A \eif C} \ii{3-5}
  \close
  \have {7} {A \eif C} \ii{2-6}
\end{fitchproof}

\subsubsection{Subproofs for Conditionals}

The resulting sub-sequence in the last proof, visibly set off from the rest of
the proof using indentation, is called a \emph{subproof}. When we use the \eif
introduction rule we collapse the subproof and treat its assumption as the
antecedant of the new conditional. At this point, the subproof is \emph{closed}.

Consider the following proof of $A\eif B, B \eif C \eproves A \eif C$.

\begin{fitchproof}
  \hypo {1} {A \eif B} \by{PR}{}
  \hypo {2} {B \eif C} \by{PR}{}
  \open
  \hypo {3} {A}        \by{AS}{}
  \have {4} {B}        \ie{1,3}
  \have {5} {C}        \ie{2,4}  
  \close
  \have {6} {A \eif C} \ii{3-5}
\end{fitchproof}

When the subproof is closed, the assumption that $A$ is true is set aside
(\emph{discharged}). We only needed it to establish that $(A \eif C)$, which is
true regardless of whether $A$ is. We should pause here and take a closer look
at this process.

Perhaps the most important point about subproofs is that their components are
meant to be used only by the subproofs themselves, not by the larger proof(s)
containing them. An open subproof must be closed; we cannot reach inside closed
subproofs.

\begin{definition}[Permissible Line Citations]
  \label{def:permissible-line-citations}
  When we want to justify a rule in a formal proof, we can only cite lines:
  %\vspace{-0.9\baselineskip}
  \begin{enumerate}
  \item that occur before the current line
  \item that do not occur in a closed subproof
  \end{enumerate}  
\end{definition}

The justification on line (5) below is not allowed (*), because we are trying
to use a line in a closed subproof, line (3), to support it.

\begin{fitchproof}
  \hypo     {1} {A}        \by{PR}{}
  \open
  \hypo     {2} {B}        \by{AS}{}
  \have     {3} {B}        \by{R}{2}
  \close
  \have     {4} {B \eif B} \ii{2-3}
  \have[5*] {5} {B}        \ie{4,3}
\end{fitchproof}

Similarly, we want to be careful when we apply rules like
\ref{def:if-introduction-rule}. We can only cite closed subproofs and they
cannot be nested too deeply.

\begin{definition}[Permissible Subproof Citations]
  \label{def:permissible-subproof-citations}
  When we want to justify a rule in a formal proof, we can only cite subproofs:
  \begin{enumerate}
  \item that occur entirely before the current line
  \item that do not occur inside another closed subproof
  \item whose last line does not occur inside a nested subproof\footnote{The
  third condition is really just a special case of the second.}
  \end{enumerate}  
\end{definition}

For example, in the following proof, we cannot apply the introduction rule
at line (7) because the subproof that we want to use to justify it, on lines
(3)-(4), itself occurs within a closed subproof. The intuition behind this is
that the subproof on lines (3)-(4) depends on the assumption of B on line (2).

\begin{fitchproof}
  \hypo     {1} {A}                           \by{PR}{}
  \open
  \hypo     {2} {B}                           \by{AS}{}
  \open
  \hypo     {3} {C}                           \by{AS}{}
  \have     {4} {A \eand B}                   \ai{1,2}
  \close
  \have     {5} {C \eif (A \eand B)}          \ii{3-4}
  \close
  \have     {6} {B \eif (C \eif (A \eand B))} \ii{2-5}
  \have[7*] {7} {C \eif (A \eand B)}          \ii{3-4}
\end{fitchproof}

\subsubsection{Rules for Biconditionals}

With this basic understanding of subproofs and definitions for \eif
introduction and \eif elimination, the rules for biconditionals are trivial. 

\Needspace{5\baselineskip}
\begin{fitchrule}[\eiff Elimination]
  \label{def:iff-elimination-rule}
  \leavevmode
  %\vspace{-0.9\baselineskip}
  There are two rules for \eiff elimination, one for each sentence: \\
  \twoitems{
    \begin{fitchproof}
      \have[m] {1} {\ephi\eiff\epsi}
      \have[n] {2} {\ephi}
      \have[ ] {3} {\epsi}           \by{\eiff E}{1,2}
    \end{fitchproof}
  }{
    \begin{fitchproof}
      \have[m] {1} {\ephi\eiff\epsi}
      \have[n] {2} {\epsi}
      \have[ ] {3} {\ephi}           \by{\eiff E}{1,2}
    \end{fitchproof}
  }
\end{fitchrule}

\Needspace{6\baselineskip}
\begin{fitchrule}[\eiff Introduction]
  \label{def:iff-introduction-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \open
    \hypo[i] {1} {\ephi}           \by{AS}{}
    \have[j] {2} {\epsi}
    \close
    \open
    \hypo[k] {3} {\epsi}           \by{AS}{}
    \have[l] {4} {\ephi}
    \close
    \have[ ] {5} {\ephi\eiff\epsi} \by{\eiff I}{1-2,3-4}
  \end{fitchproof}
\end{fitchrule}

Here we see a proof that uses both the introduction and elination rules for
\siff to show its transitivity.

\begin{fitchproof}
  \hypo     {1} {A \eiff B}        \by{PR}{}
  \hypo     {2} {B \eiff C}        \by{PR}{}
  \open
  \hypo     {3} {A}                \by{AS}{}
  \have     {4} {C}                \by{\eiff E}{2}
  \close
  \hypo     {5} {C}                \by{AS}{}
  \have     {6} {A}                \by{\eiff E}{1}
  \close
  \have     {1} {A \eiff C}        \by{\eiff I}{3-4.5-6}
\end{fitchproof}

\subsubsection{Rules for Disjunction}

The last few operators are more challenging to define. The first of these,
disjunction (\eor), because its elimination requires us to check more than one
possibility.

Introduction, however, is quite straightforward.

\Needspace{5\baselineskip}
\begin{fitchrule}[\eor-Introduction]
  \label{def:eor-introduction-rule}
  \leavevmode
  %\vspace{-0.9\baselineskip}
  There are two rules for \eor-introduction, one for each sentence: \\
  \twoitems{
    \begin{fitchproof}
      \have[n] {1} {\ephi}
      \have[ ] {2} {\ephi\eor\epsi}  \oi{1}
    \end{fitchproof}
  }{
    \begin{fitchproof}
      \have[n] {1} {\epsi}
      \have[ ] {2} {\ephi\eor\epsi}  \oi{1}
    \end{fitchproof}
  }
\end{fitchrule}

We can handle the ambiguity involved in disjunction elimination with multiple
subproofs, much as we do when introducing biconditionals.

\Needspace{8\baselineskip}
\begin{fitchrule}[\eor-Elimination]
  \label{def:eor-elimination-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \have[j] {1} {\ephi\eor\epsi}
    \open
    \hypo[i] {2} {\ephi}  \by{AS}{}
    \have[j] {3} {\echi}
    \close
    \open
    \hypo[k] {4} {\epsi}  \by{AS}{}
    \have[l] {5} {\echi}
    \close
    \have[ ] {6} {\echi}  \oe{1, 2-3,4-5}
  \end{fitchproof}
\end{fitchrule}

Now that we have almost a complete set of rules for the basic operators of TFL,
we can prove a variety of valid arguments, such as this one demonstrating the
distributivity of \sand and \eor.

\begin{fitchproof}
  \hypo {1} {A \eand (B \eor C)}          \by{PR}{}
  \have {2} {A}                           \ae{1}
  \have {3} {B \eor C}                    \ae{1}
  \open
  \hypo {4} {B}                           \by{AS}{}
  \have {5} {A \eand B}                   \ai{2,4}
  \have {6} {(A \eand B)\eor(A \eand C)}  \oi{5}
    \close
  \open
  \hypo {7} {C}                           \by{AS}{}
  \have {8} {A \eand C}                   \ai{2,7}
  \have {9} {(A \eand B)\eor(A \eand C)}  \oi{8}
  \close
  \have {10} {(A \eand B)\eor(A \eand C)} \oe{3,4-6,7-9}
\end{fitchproof}

\subsubsection{Rules for Negation}

An attentive reader will probably have noticed that we have not yet mentioned
the negation operator (\enot). The nature of negation in TFL is wrapped up in
two of its core assumptions: \emph{non-contradiction} and \emph{the excluded
middle}. We've seen these before:

%\begin{argument}
%\item[\textbf{LEM:}] \ephi\eor\enot\ephi
%\item[\textbf{LNC:}] \enot(\ephi\eand\enot\ephi)
%\item[\textbf{DN:}]  \enot\enot\ephi\eiff\ephi  
%\end{argument}
\begin{center}
    \textbf{LEM:} $\ephi\eor\enot\ephi$         \\
    \textbf{LNC:} $\enot(\ephi\eand\enot\ephi)$ \\
    \textbf{DN:} $\enot\enot\ephi\eiff\ephi$    \\
\end{center}

The first (\textbf{LEM}) says that one of either \ephi or \enot\ephi must be
true. The second (\textbf{LNC}) says that \ephi and \enot\ephi cannot both be
true. To accomomdate these assumptions, especially the second, we introduce an
additional symbol into our object language for TFL (\ebot) which we will use
when we encounter a contradiction. We know that the negation of \textbf{LNC}
(a tautology) is a contradiction. In formulating rules for negation, instead of
leveraging \textbf{LNC}, we can instead leverage its negation, as in
\textbf{LNC2}.

%\begin{argument}
%\item[\textbf{LNC2:}] \ephi\eand\enot\ephi\eentails\ebot
%\end{argument}
\begin{center}
    \textbf{LNC2:} $\ephi\eand\enot\ephi\eentails\ebot$
\end{center}

There are several ways to think about $\ebot$ (e.g. as a zero-place connective
or as a logical constant), but we will assume that it is just a sentence that is
always false, regardless of situation. This makes it easy to use in other rules
and does not obscure its use to indicate a contradiction. Given \textbf{LNC2},
the elimination rule is simple.

\Needspace{4\baselineskip}
\begin{fitchrule}[\enot Elimination]
  \label{def:not-elimination-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \have[m] {1} {\enot\ephi}
    \have[n] {2} {\ephi}
    \have[ ] {3} {\ebot}      \ne{1,2}
  \end{fitchproof}
\end{fitchrule}

We will need to wait for some rules that tell use what to do with $\ebot$ before
we can demonstrate \enot elimination in proofs.

Recall reductio ad adsurdum (RAA) from the first lecture (\ref{def:raa}),
repeated here:

\begin{definition}[Reductio Ad Absurdum]
  \label{def:raa-repeated}
  If $\ephi_1\dots\ephi_n$ are taken as premises and the addition of \spsi would
  result in a contradiction, then $\ephi_1\dots\ephi_n$ entails \enot\epsi.
\end{definition}

So how do we introduce a negation? We assume the non-negated sentence and use
a subproof to show that this assumption leads to a contradiction. The
introduction rule for negation references subproofs of this form in its
justification.

\Needspace{4\baselineskip}
\begin{fitchrule}[\enot Introduction]
  \label{def:not-introduction-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \open
    \hypo[m] {1} {\ephi}      \by{AS}{}
    \have[n] {2} {\ebot}
    \close
    \have[ ] {3} {\enot\ephi} \ni{1-2}
  \end{fitchproof}
\end{fitchrule}

Now we can demonstrate both negation rules with a proof.

\begin{fitchproof}
  \hypo {1} {\enot (A \eor B)}                       \by{PR}{}
  \open
  \hypo {2} {(A \eor B)\eand(C \eand\enot D)}        \by{AS}{}
  \have {3} {A \eor B}                               \ae{2}
  \have {4} {\ebot}                                  \ne{1,3}
  \close
  \have {5} {\enot((A \eor B)\eand(C \eand\enot D))} \ni{2-4}
\end{fitchproof}

\subsubsection{Indirect Proof and Explosion}

Of course, the symmetry of negation lets us work in the opposite direction,
too. We will call this method: \emph{indirect proof}, since it does not involve
the introduction or elimation of any operators outside of the subproof.

\Needspace{4\baselineskip}
\begin{fitchrule}[Indirect Proof]
  \label{def:indirect-proof-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \open
    \hypo[m] {1} {\enot\ephi} \by{AS}{}
    \have[n] {2} {\ebot}
    \close
    \have[ ] {3} {\ephi}      \by{IP}{1-2}
  \end{fitchproof}
\end{fitchrule}

Indirect proof is really just a reversal of the \enot I rule. IP is convenient
for proving double-negative elimination (\textbf{DNE}):
$\enot\enot A \eproves A$

\begin{fitchproof}
  \hypo {1} {\enot\enot A} \by{PR}{}
  \open
  \hypo {2} {\enot A}      \by{AS}{}
  \have {3} {\ebot}        \ne{1,2}
  \close
  \have {4} {A}            \by{IP}{2-3}
\end{fitchproof}

One additional rule can be thought of as $\ebot$ elimination. A long-standing
assumption in classical logic is that proving a contradiction allows us to
conclude anything at all (\emph{ex falso quodlibet}). This follows trivially
from the fact that we cannot find a bad line in entailments with a pair of
contradictions in the premises because there is no situation in which they are
all true.

\begin{argument}
  \item[\textbf{X:}] $\ebot\eentails\ephi$ for any TFL sentence \ephi.
\end{argument}

We will refer to this kind of inference step as \emph{explosion}. Like vacuous
material implication, not everyone loves this aspect of logic (especially at
first). Nevertheless it is effective and widely adopted.

\begin{quote}
  [O]fficial definitions of entailment--as with many other definitions of
  logical concepts--are best thought of as rational reconstructions of our
  messy pre-theoretic ideas. We try to fit the range of informal desiderata as
  best we can, balancing considerations of theoretical simplicity and ease of
  use against the cost of departures from our initial intuitions.
  (from \cite[][p. 145]{Smi20})
\end{quote}

\Needspace{3\baselineskip}
\begin{fitchrule}[Explosion]
  \label{def:explosion-rule}
  \leavevmode
  \vspace{-0.9\baselineskip}
  \begin{fitchproof}
    \have[m] {1} {\ebot}
    \have[ ] {2} {\ephi} \by{X}{1}
  \end{fitchproof}
\end{fitchrule}

We can prove the \emph{disjunctive syllogism} rule
($A \eor B, \enot A \eproves B$) using explosion:

\begin{fitchproof}
  \hypo {1} {A \eor B} \by{PR}{}
  \hypo {2} {\not A}   \by{PR}{}
  \open
  \hypo {3} {A}        \by{AS}{}
  \have {4} {\ebot}    \ne{2,3}
  \have {5} {B}        \by{X}{4}
  \close
  \open
  \hypo {6} {B}        \by{AS}{}
  \have {7} {B}        \by{R}{6}
  \close
  \have {8} {B}        \oe{1,3-5,6-7}
\end{fitchproof}
